# Rancher Manager（单机评估环境）

## 启动

```bash
cd /root/deAI/infra/rancher
docker compose up -d
```

## 访问

- 首次启动需等待 1~2 分钟（容器内下载/初始化）。
- 访问 `https://<宿主IP>:8443`（HTTP 为 `8080`）。
- 首次会要求设置 admin 初始密码，设置后进入控制台。

## 端口说明

| 宿主端口 | 容器端口 | 用途 |
|---|---|---|
| 8080 | 80 | HTTP（会重定向到 HTTPS） |
| 8443 | 443 | HTTPS 控制台 |

## 数据

- `./data` 挂载到容器 `/var/lib/rancher`，持久化集群数据与配置。

## 注意事项

1. **仅用于评估/沙盒**：官方 v2.14 已推荐 Helm 方式部署，Docker 单容器方式适合本地测试，不建议直接用于生产。
2. **端口冲突**：已避开本机现有服务占用的端口（5000/3000/9090/9400/8082/2222/3100/5100/5901/18000）。
3. **privileged**：Rancher 官方 Docker 安装要求特权模式，请知悉其安全影响。
4. 停止与清理：`docker compose down`（数据保留在 `./data`）。
